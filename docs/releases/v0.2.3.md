# ipcprims v0.2.3

> Released: 2026-07-07

Fast-follow release for dependency hygiene, MSRV alignment, and TypeScript runtime floor cleanup after v0.2.2.

## Highlights

- **Rust MSRV aligned at 1.88.0**: The workspace, CI MSRV job, tag-triggered MSRV matrix, `make msrv`, README badge, and development/CICD docs now agree on Rust 1.88.0.
- **Schema validation refreshed**: `jsonschema` moved from 0.41 to 0.46.10. The manifest disables default features and explicitly selects `resolve-http`, `resolve-file`, and `tls-ring` so ipcprims keeps the ring-backed TLS posture instead of silently taking the newer default TLS provider.
- **Dependency lockfile refreshed**: The Rust lockfile was refreshed within compatible constraints, including updates to the HTTP/TLS stack used by schema resolution.
- **Node runtime floor set to 20+**: The published TypeScript package now declares Node.js `>=20`, matching the CI and prebuild workflows.
- **TypeScript 6 ready**: TypeScript dev tooling moved to 6.0.3, with `Node16` module resolution and explicit test `rootDir` configuration for TS 6 compatibility.

## Compatibility

- **Rust**: Minimum supported Rust version is now 1.88.0 across the workspace.
- **Node.js**: TypeScript bindings now require Node.js 20 or newer at runtime.
- **Schema behavior**: The `jsonschema` update includes validation/reference correctness fixes. Consumers relying on previously accepted invalid schemas or instances should treat this as a validation-behavior tightening risk and run schema-focused tests.

## Deferred

- **NAPI-RS major line**: `@napi-rs/cli` 3.x and Rust `napi`/`napi-derive` 3.x are deferred. The CLI 3 command surface changes existing build/prebuild flags, and Rust NAPI 3 changes async/JS reference APIs used by `ipcprims-napi`.
- **Node 22+ or 26+ floor**: Runtime support remains `>=20` for this release. Any higher floor should be handled with a separate consumer-support decision.
