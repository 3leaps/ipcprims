# ipcprims v0.2.4

> Released: 2026-08-21

Patch release for a compatible Rust lockfile refresh after v0.2.3. The driver is `h2` 0.4.18 on the schema HTTP resolver path.

## Highlights

- **Compatible lockfile refresh**: workspace `Cargo.lock` updated within existing constraints.
- **`h2` 0.4.18**: reached via `jsonschema` → `reqwest` (schema HTTP resolve / `tls-ring`). This is not a change to the UDS or named-pipe peer transport.
- **Go Bindings Prep required**: rebuild committed Go natives for this cut even when FFI source is unchanged. The workflow is `--locked` against the workspace graph.

## Dependency Notes

- `h2`: 0.4.15 -> 0.4.18
- `rustls`: 0.23.41 -> 0.23.43 (stays on 0.23.x)
- `tokio`: 1.52.3 -> 1.53.1
- `jsonschema`: 0.46.10 (unchanged)
- napi 2.16.x (unchanged)

## Compatibility

- **Rust**: MSRV remains 1.88.0.
- **Node.js**: TypeScript runtime floor remains Node.js 20+.
- **Downstream lockfiles**: this does not force consumers with their own `Cargo.lock` to take the new `h2`. It fixes repo-built artifacts and CI.
- **Peer transport / handshake / framing**: no intended behavior change.

## Deferred

- **NAPI-RS major line**: `@napi-rs/cli` 3.x and Rust `napi`/`napi-derive` 3.x remain deferred.
- **`jsonschema` 0.50**: held for a separate schema-behavior review.
